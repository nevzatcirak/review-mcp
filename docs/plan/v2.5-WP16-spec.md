## Items

1. **`fix(repotools): count skipped files in words`**
   - The search result says "1 files were not searched: they were not fetched." It must use the `llmrun.CountPhrase` form: "1 file was not searched: it was not fetched." and "N files were not searched: they were not fetched."
   - Also grep the code for every other count written as `strconv.Itoa(n) + " <plural noun>"` or `fmt.Sprintf("%d <plural noun>", …)` in text a user or a model reads. Fix each one the same way, in this commit, and list them in the report.
   - Test: 1 and 2 for each fixed site.
   - Canary: restore the old search text, and the 1-file test fails.

2. **`fix(gitctx): remove stale read-view temp directories`**
   - When `ensureView` runs, it removes every `<cache>/.view-*.tmp*` directory whose modification time is older than one hour. Use the same "never follow a link, stay inside the root" rules as `removeView`.
   - A younger one is left alone, because another process may be building it.
   - Test: an old one is removed, a young one is kept, and a link named like one is removed as a link, never its target.
   - Canary: skip the age check, and the young-one test fails.

3. **`fix(ask): link citations with several lines`**
   - A `pr_ask` citation `R<n>:path:L`, `:L-M` or `:L,M[,K…]` becomes one link to line `L`. The link text is the whole citation as the model wrote it (for example `…/header.ts:1,6`).
   - Nothing of the citation stays outside the link: in 2.5.1 a stray "`,6`" was left behind.
   - The seen-file rule and "(location not verified)" are unchanged.
   - Test: each form, plus an unseen file.
   - Canary: drop the `,` form, and its test fails.

4. **`fix(repocfg): give the related-repositories note only where it could apply`**
   - The note "The repository config names related repositories, but reading them is turned off by the operator (related.from_repo_config)." is given only by a run that would have read the declarations if the switch were on: `pr_review` and `pr_ask` without their own `related`, not focused, and not a merged publish.
   - `pr_describe` and `pr_improve` never give it. `related.repos` still appears in `repo_config.ignored` in every case, unchanged.
   - Test: each tool and mode.
   - Canary: give the note in a focused run, and the test fails.

5. **`docs: document the remaining keys`**
   - `bitbucket_server.insecure_skip_verify` (`REVIEW_MCP_BITBUCKET_SERVER_INSECURE_SKIP_VERIFY`) goes in `docs/setup.md`, next to the other providers' `insecure_skip_verify`, with the same warning.
   - Cross-check `internal/config/table.go` once more and report any key still missing.
   - Troubleshooting rows for the texts changed by items 1, 3 and 4.
   - CHANGELOG `## [Unreleased]`, planned as `2.5.2`, under "Fixed".
